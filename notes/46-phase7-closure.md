## 2. A1 — the finding, stated with its limits

> **A1 demonstrated strong within-generator generalization but failed
> cross-distribution transfer.** The supplementary corpus is
> catalog-metadata-grounded and rewards category, exact-match and IDF signals;
> the public Amazon 5-core sessions carry a much stronger popularity prior. A1
> reduced `w_pop` from 4.0 to 1.0 and increased lexical/category weights,
> improving supplementary MRR while reducing public MRR. **Popularity is the
> strongest measured explanation, but not claimed as the sole factor because no
> post-public ablation was performed.**

Four qualifications that must travel with that statement:

1. **`sup-train` and `sup-val` are the same distribution** — both are drawn from
   `supplementary_dev`, generated by the same generator. `sup-val` therefore
   demonstrates **within-generator generalization only**. It is not evidence
   about the public set, and it is not evidence about real users.
2. **The full-Agent `sup-val` run improved too**, so the gain is *not* an
   artefact of the off-policy feature cache. A1's on-policy `sup-val` MRR delta
   (**+0.228613**) exceeded its cached `sup-train` delta (+0.219693) — the cache
   understated the arm rather than inflating it.
3. **Every public slice and every robustness scenario regressed.** Not a mixed
   picture with one bad slice: `boundary` −0.175, `buying` −0.136, `browsing`
   −0.118, `intent_override` −0.042 on MRR, and −0.043 to −0.130 on paired
   robustness composite.
4. **The supplementary gain must never be written as a real-user effect.** The
   corpus is synthetic and generator-grounded; the number describes that
   generator.

## 3. A2-10 — the definition, used verbatim everywhere

> **A2-10 is a selective local transformer cross-encoder cascade.** After A0
> retrieval, reranking and request-more rotation, it reorders only a copy of the
> final visible Top-10. It never adds or removes an item, so **HR@10 and MTTC
> are invariant; only MRR can change.** It runs only on eligible early
> Browsing/Mixed turns and falls back **byte-exactly** to A0 on any unavailable
> or invalid model path.

Disclosed with it, always:

| | |
|---|---|
| model | `cross-encoder/ms-marco-TinyBERT-L2-v2` |
| revision | `81d1926f67cb8eee2c2be17ca9f793c7c3bd20cc` |
| form | local quantized ONNX (`onnx/model_qint8_arm64.onnx`) |
| scope | **Top-10 only** |
| activation | **~8.5–8.9% of turns** (390/4402 `sup-train`, 97/1142 `sup-val`) |
| Top-10 p95 | **15.95 ms** |
| RSS | **+131.6 MB** |
| `sup-val` MRR | **+0.008248** |
| λ | **1.0** |
| public result | **none — never run** |
| in `score_default` | **off** |

**It is a transformer semantic reranker, not a generative LLM.** It emits no
text, takes no instructions, and produces one relevance score per
(query, product) pair.

### Why it is feature-off

It was eliminated at `notes/44` §7b Step 2 — A1 won finalist selection on higher
`sup-val` MRR — so **A2-10 has no public number and cannot be defaulted on**.
Its `sup-val` gain is +0.008248, which is real and small, and it costs a pinned
model, an ONNX runtime and a vendored artifact. Shipping it on would be claiming
a benefit no public measurement supports.

## 4. The final default

`score_default` is A0: Buying/Browsing/Mixed routing, deep funnel on, starvation
bypass on, retrieval context control on, question context control on, semantic
off, dense off, profile ranking weight off. **Python standard library only, zero
network, zero API cost, token usage 0.**

## 5. Stop conditions — what Phase 7 forbids from here

Nothing below may be done for this submission:

* running A2-10 on the public 200, as a consolation or otherwise;
* modifying A1's weights;
* extending the λ grid;
* changing the semantic model;
* retraining or tuning anything;
* modifying `score_default`'s retrieval, dialogue, context or ranking behaviour;
* changing any configuration in response to a sealed-holdout result.

**Phase 7 accepts only closure notes, configuration-lock tests and factual
documentation. No behavioural change.**
